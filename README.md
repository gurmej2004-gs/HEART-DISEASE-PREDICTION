# Heart Disease Prediction

A machine learning project that explores patient health data to predict the presence of heart disease. The project is implemented using Python and Jupyter Notebook and includes data analysis, preprocessing, and machine learning-based prediction.

## 📌 Overview

This project uses heart disease datasets to analyze medical attributes associated with heart disease and build a predictive machine learning workflow.

The project focuses on understanding the data, preparing it for analysis, identifying relevant patterns, and applying machine learning techniques for prediction.

## 🎯 Objectives

* Analyze and understand heart disease patient data.
* Perform data cleaning and preprocessing.
* Explore relationships between medical attributes.
* Apply machine learning techniques for classification.
* Evaluate the prediction results.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/gurmej2004-gs/HEART-DISEASE-PREDICTION.git
```

### 2. Open the project

```bash
cd HEART-DISEASE-PREDICTION
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

Open:

```text
heart_disease_prediction.ipynb
```

and run the notebook cells.
